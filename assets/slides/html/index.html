Lab 1

Three Traps to Watch For

Zero vs. missing

A firm with no R&D tag is missing, not zero. Filling it with zero changes the median.

Duplicate firm-years

A 10-K also reports last year’s values. Keep the value for the filing’s own period.

Memory

num.txt is large. Read one quarter at a time and keep only the tags you need.

Tag coverage differs by quarter. Measure it in DATA_PROFILE.md before you trust a median.

Drill 1

Check 1: Credential Files in History

git log --all --full-history --oneline -- '*.env' '*.env.*' '.mcp.json'
  • Expected output: nothing
  • Finds a .env file or a variant such as .env.local, in any folder, at any point in the history, plus a project-level .mcp.json
  • Deleting the file now does not remove it from history

Drill 1

Check 2: Your Actual Key

read -s SECRET
git log --all --oneline -S"$SECRET"
git grep -l -F --untracked -e "$SECRET"
  • Paste the key after read -s; it won’t echo. Expected output: nothing
  • The two searches print commit IDs or file names, never the key
  • No API keys in this project? Run Check 1 only

If either check finds something

Revoke and rotate the key first. Clean the history second.

Drill 1 · rehearsal

Deleting It Does Not Remove It

In the practice clone, git log -S still finds both the commit that added the fake key and the one that deleted it.

Drill 2: The Clean-Room Referee

mkdir -p ~/referee_room/paper ~/referee_room/.claude

  • A deny rule stops it from editing the files
  • Ask for the three most serious objections, written to review/

Drill 2

Why a Separate Room

Same session

has heard every reason you gave for each filter

tends to accept your design

Clean room

sees only the text a reader would see

has to rebuild the sample from it

A referee that agrees with you

If the report is mostly praise, or backs down when you object, ask again for the three most serious problems. Answer it in the report file, not in the chat.

Drill 3

Drill 3: One Deny Rule, Tested

In .claude/settings.json:

{
  "permissions": {
    "deny": [
      "Edit(./fsds/**)"
    ]
  }
}

Raw data stays read-only.

Test it

  1. Start a new session in the project
  2. Run /permissions and find the rule
  3. Ask Claude to edit a file in fsds/
  4. It should refuse. Paste what it said

Deny rules hold in every mode. They block file tools and shell commands that name the path, but not a Python script that opens the file. Only a sandbox stops that.

Reading 1

Brodeur et al. (2026), PNAS

  • 288 researchers in 103 teams reproducing published papers
  • AI-assisted teams matched human-only teams on reproduction

Reading 2

Kusumegi et al. (2025), Science

LLM adopters post
24–89%
more papers
Polished prose stops signaling quality
  • Preprints before and after authors start using LLMs
  • The range is across the preprint servers studied
  • Among adopters, more complex writing no longer goes with a better paper

If writing gets cheap and stops signaling quality, readers and referees have to look somewhere else.

Discussion

Three Questions

1
Knowledge vs. learning. Which step of today’s pipeline would you not let an agent do for you in your first paper, because doing it is how you learn the data?
2
Who did the work. Brodeur et al.’s AI-assisted teams reproduced as often but missed more major errors. Which item on your verify checklist would have caught one?
3
Returns to research. If anyone can build today’s figure in 50 minutes and polished prose no longer signals quality, which parts of your work stay hard to do?
